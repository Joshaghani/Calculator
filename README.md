# 🧮 Java CLI Calculator

این پروژه یک ماشین‌حساب ساده با زبان جاوا است که در محیط خط فرمان (Command Line) اجرا می‌شود.  
در این پروژه کاربر می‌تواند عملیات ریاضی پایه را به صورت پیوسته انجام دهد تا زمانی که عملگر `=` را وارد کند.

## 📌 ویژگی‌ها

- پشتیبانی از عملیات جمع، تفریق، ضرب و تقسیم
- اجرای پشت‌سرهم عملیات‌ها
- دریافت ورودی از کاربر با `Scanner`
- خروج با وارد کردن علامت `=`
- مدیریت خطاهای ورودی عددی

---

## 🛠️ نحوه اجرا

1. فایل `Main.java` را ایجاد کرده و کد را در آن قرار دهید.
2. در ترمینال دستورهای زیر را اجرا کنید:

```bash
javac Main.java
java Main
